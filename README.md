🛒 Lista de Compras em Java

Aplicação Java para gerenciamento de lista de compras, desenvolvida utilizando **Java Swing** (`JOptionPane`) para interface gráfica nativa e a estrutura de dados **HashMap** para controle de produtos e quantidades.

---

Funcionalidades

- **Adicionar Produtos:** Permite cadastrar itens na lista. Caso o produto já exista, a quantidade é incrementada automaticamente.
- **Consultar Lista:** Exibe todos os itens cadastrados com as suas respectivas quantidades e calcula o total acumulado.
- **Interface Gráfica:** Navegação interativa baseada em caixas de diálogo nativas do sistema.

---

Tecnologias Utilizadas

- **Linguagem:** Java (JDK 17+)
- **Estrutura de Dados:** `java.util.HashMap`
- **Interface Gráfica:** `javax.swing.JOptionPane`
- **IDE:** IntelliJ IDEA
